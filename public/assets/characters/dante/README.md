# Dante — Centre Court character assets

Upload the approved rigged 3D character as a **.glb** file into this folder using GitHub's **Add file → Upload files**.

Preferred filename: `dante.glb`.

Optional reference images may be kept alongside it as PNG or JPG files.

This directory serves production files at `/Centre-Court/assets/characters/dante/` via Vite/GitHub Pages. Uploading a GLB does not automatically make the character playable; integration must verify bone hierarchy, animation retargeting, racket attachment, model scaling, texture loading and runtime performance.

Do not store passwords, licenses containing personal information, or other private data in this public repository.
